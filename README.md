A one-line review of planet Earth filed by an alien tourist after two days of field observation: the natives' nightly ritual of lying down to hallucinate in unison, rated four stars. The program writes the single line to /output/entry.txt.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
